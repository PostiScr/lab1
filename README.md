# система управления персоналом

лабораторная работа по прикладному программированию. консольное приложение, 
в котором можно добавлять сотрудников разных должностей, просматривать их список, 
изменять зарплату и удалять их из базы.

## запуск

нужен python 3.10 или новее. в pycharm или vs code запустить `main.py` или из папки проекта:

```bash
python3 main.py
```

в меню нужно выбрать действие и ввести запрошенные данные. сотрудники
выбираются по id, который вводится при создании.
данные сохраняются в файле `employees.json` в папке проекта и загружаются при следующем запуске.

## структура проекта

| файл/папка | назначение |
| --- | --- |
| `main.py` | запуск программы, сборка зависимостей |
| `domain/` | классы сотрудников, исключения и интерфейс хранилища |
| `application/` | бизнес-логика, правила и проверки |
| `infrastructure/` | сохранение и загрузка данных в `json` |
| `presentation/` | консольное меню, ввод/вывод и обработка ошибок |
| `tests/` | юнит-тесты для проверки бизнес-логики сервиса |

## пример работы

1. выбрать пункт 2, создать разработчика (`Developer`) с id `1`, именем `Иван`, зарплатой `50000`, языком программирования `Python`.
2. снова выбрать пункт 2, создать менеджера (`Manager`) с id `2`, именем `Мария`, зарплатой `85000`, количеством подчинённых `5`.
3. выбрать пункт 1, чтобы посмотреть список всех сотрудников.
4. через пункт 3 изменить зарплату сотрудника с id `1`.
5. через пункт 4 удалить сотрудника с id `2`.

## правила и ошибки

- id сотрудника должен быть уникальным и являться натуральным числом;
- зарплата должна быть строго больше нуля;
- при добавлении сотрудника обязательно указывается его должность (разработчик, менеджер и т.д.);
- нельзя удалить или изменить зарплату сотруднику, которого нет в базе.

если введены неверные данные или нарушены правила, программа показывает
сообщение об ошибке и возвращается к меню.
